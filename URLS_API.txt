Notes
-----
- Remplacer {APP_URL} par l'adresse du serveur.
- Remplacer {id}, {compte}, {role}, {permission}, {action} et {menu} par une valeur reelle.
- Les routes protegees necessitent generalement : Authorization: Bearer {token}
- Source verifiee avec : php artisan route:list --path=api
- Total Laravel : 106 routes HTTP (les methodes GET incluent automatiquement HEAD).
